# Operations Manual

## 1. Daily Opening Routine
See `SOP_DAILY_ROUTINE.md` for the minute-by-minute checklist.

### 6:00 AM — Store Prep
- Verify inventory counts against `PRODUCT_PRICING.csv`
- Check rider attendance via WhatsApp group
- Load fresh stock into catalog images

### 7:00 AM — Dashboard Live
- Open Tech Dashboard (`src/web/dashboard/index.html`)
- Verify yesterday's orders synced
- Check rider locations on map

### 8:00 AM — Orders Begin
- WhatsApp orders start flowing
- Assign riders based on zone and load
- Send daily summary to operations channel

## 2. Partner Store Operations
- **Onboarding:** See `PARTNER_AGREEMENT.md`
- **Pricing:** Daily check via `DAILY_PRICE_CHECKLIST.txt`
- **Quality:** Random spot-checks; non-compliant stock returned
- **Payouts:** Weekly, every Monday via bank transfer

## 3. Rider Operations
- **Check-in:** Morning huddle using `DAILY_HUDDLE_TEMPLATE.txt`
- **Dispatch:** Zone-based assignment, WhatsApp dispatch message
- **Tracking:** Live map in dashboard
- **Cash Handling:** Rider logs in `RIDER_DAILY_LOG.txt`

## 4. Customer Service
- **WhatsApp:** First-line support
- **Escalation:** Issues > 2 hours → ops manager call
- **Refunds:** Store credit first, cash refund for SLA breach
- **Scripts:** See `07_Marketing/WHATSAPP_BATTLE_CARDS.txt`

## 5. Financial Reconciliation
- End-of-day report auto-generated by `daily_summary.py`
- Finance dashboard updated by 10:00 PM
- Weekly review every Sunday via `WEEK1_REPORT_TEMPLATE.txt`

## 6. Emergency Protocols
See `EMERGENCY_PROTOCOLS.md` for:
- Rider accident / breakdown
- Store stock-out at peak
- Payment gateway failure
- Customer complaint escalation

---

*This manual is a living document. Update after every incident or process change.*
