Order Processing (8:00 AM - 9:00 AM):

  2. Send auto-reply to each customer
  3. Calculate totals

  2. Collect from all partners
  3. Sort and pack at hub
  4. Deliver by building cluster
  5. Collect payment, update sheet

End of Day (9:00 PM):
  1. Reconcile all payments
  2. Update financial tracker
  3. Update KPI dashboard
  4. Respond to pending messages
  5. Set WhatsApp auto-reply for after-hours

═══════════════════════════════════════════════════════════════════════════════
EMERGENCY PROTOCOLS
═══════════════════════════════════════════════════════════════════════════════

If Rider Unavailable:
  □ Call backup rider immediately
  □ If no backup: partner delivers directly (+30 BDT to customer)
  □ Inform affected customers of 30-min delay
  □ Offer 50 BDT credit

If Partner Fails:
  □ Switch to backup partner immediately
  □ Inform customer only if item unavailable
  □ Never blame partner to customer
  □ Document failure, adjust partner score

If Customer Complains:
  □ Apologize, offer specific fix + 50 BDT credit
  □ Document in Customer Database
  □ Follow up next day
