## 🚀 Quick Start Guide

### First 7 Days
1. **Day 1**: Read `04_Operations/ENHANCED_SOP_MANUAL.txt` + `04_Operations/OPERATIONS_PLAYBOOK.txt`
2. **Day 2**: Set up WhatsApp Business with logo from `02_Brand_Assets/logo.svg`
3. **Day 3**: Visit Krishi Market with `04_Operations/grok_playbooks/08_JG_Mart_Partner_Guide_v1.2.txt`
4. **Day 4**: Print flyers using `02_Brand_Assets/kimi_originals/04_JG_Mart_Flyer_A5.png`
5. **Day 5**: Run `10_Launch_Readiness/LAUNCH_READINESS_CHECKLIST.txt`
6. **Day 6**: Use `04_Operations/grok_playbooks/JG_Mart_First_Launch_Day_Runbook.txt`
7. **Day 7**: Complete `10_Launch_Readiness/WEEK1_REPORT_TEMPLATE.txt`

### Daily Operations
- **Morning (6-9AM)**: `04_Operations/MORNING_ROUTINE_CHECKLIST.txt`
- **Orders**: `05_Tech_Dashboard/orders.html` or `06_Web_Catalog/order_intake.html`
- **Financials**: Update `08_Financials/ENHANCED_FINANCIAL_TRACKER.csv`
- **Marketing**: Post `02_Brand_Assets/kimi_originals/05_JG_Mart_WhatsApp_Catalog.png`

### For Investors
1. `01_Investor_Deck/EXECUTIVE_SUMMARY.txt` — quick overview
2. `01_Investor_Deck/grok_decks/JG_Mart_Investor_Visual_Pitch_Deck.pptx` — live presentation
