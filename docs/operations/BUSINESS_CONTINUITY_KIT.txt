STEP 3: WHAT TO DO IF YOUR MAIN COMPUTER DIES
═══════════════════════════════════════════════════════════════════════════════

SCENARIO: Laptop dies during operations

  1. Plug USB into any Windows computer
  2. Open USB drive → double-click LAUNCH_CENTER.bat
  3. Click "Open All Apps" → all 9 web apps open in browser
  4. Open QUICK_START.txt → continue your day
  5. Your data is lost (localStorage doesn't sync across computers)
     → BUT you can export data from each app as JSON before switching

SCENARIO: Need to work from a phone/tablet

  The HTML apps won't work well on phones (they're desktop web apps).
  Instead, use:
    • WhatsApp Business app for customer communication
    • Google Sheets (import from 12_Templates/GOOGLE_SHEETS_IMPORT.txt)
    • Printed forms from 11_Day1_Launch_Kit/

SCENARIO: Need to work from another person's computer

  1. Plug in USB
  2. Open index.html → all apps available
  3. Data won't sync, but you can:
     a. Take screenshots of key numbers before switching
     b. Export JSON data from each app
     c. Re-enter on the new machine

═══════════════════════════════════════════════════════════════════════════════
IMPORTANT DATA NOTE
═══════════════════════════════════════════════════════════════════════════════

Each web app stores its data in your browser's localStorage.
This data is NOT in the files — it's in your browser profile.

This means:
  ✓ Apps work offline
  ✓ Data persists when you close/reopen
  ✗ Data does NOT sync across computers
  ✗ Clearing browser cache = losing all data

SOLUTION: Export regularly using each app's Export button.
The exported JSON files contain ALL your data and can be re-imported.
